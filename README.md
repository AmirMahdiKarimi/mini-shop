# فروشگاه کوچک

برنامهٔ مدیریت موجودی و فروش با Python، SQLite و Tkinter. همان منطق از رابط گرافیکی و متنی استفاده می‌کند و به کتابخانهٔ جانبی نیاز ندارد.

## اجرا

```powershell
python main.py
python main.py --cli
python -m unittest discover -s tests -v
```

داده‌ها در `shop.sqlite3` کنار برنامه ذخیره می‌شوند. مسیر آن در ثابت `DATABASE_PATH` داخل `shop/config.py` تعریف شده است. نسخهٔ Python 3.10 یا جدیدتر پیشنهاد می‌شود. در محیط بدون نمایشگر از `--cli` استفاده کنید.

## رفتار داده‌ها

- مبالغ، عدد صحیح ریال هستند و مقدار اعشاری پذیرفته نمی‌شود.
- نام کالای فعال پس از یکسان‌سازی فاصله‌ها یکتا است. پس از بایگانی می‌توان کالایی با همان نام ثبت کرد؛ سابقهٔ کالای قبلی جدا می‌ماند.
- حذف کالا، بایگانی‌کردن آن است؛ سابقهٔ فروش پاک نمی‌شود. بایگانی با هر مقدار موجودی مجاز است.
- هر فروش قیمت همان لحظه را ثبت می‌کند. تغییر بعدی قیمت، گزارش‌های قبلی را عوض نمی‌کند.
- فروش، کاهش موجودی و ثبت تراکنش در یک تراکنش SQLite انجام می‌شود. ویرایش، فروش و بایگانی با شمارهٔ نسخه از نوشتن روی دادهٔ قدیمی جلوگیری می‌کنند.
- تاریخ‌های گزارش به وقت ایران (UTC+03:30) و با دو سرِ شامل وارد می‌شوند.

## ساختار

`shop/models.py` مدل و قواعد پایه، `shop/service.py` اعتبارسنجی و کاربردها، `shop/storage.py` ذخیره‌سازی تراکنشی، `shop/gui.py` رابط Tkinter، و `shop/cli.py` رابط متنی را نگه می‌دارند. رابط‌ها فقط از سرویس استفاده می‌کنند.

## نمونهٔ رابط گرافیکی

در زبانهٔ «کالاها» کالا اضافه یا انتخاب و ویرایش می‌شود. «تعداد اولیه» فقط هنگام افزودن کالای جدید فعال است. برای افزایش موجودی، کالا را انتخاب کنید و دکمهٔ «افزایش موجودی» را بزنید؛ تعداد در پنجرهٔ کوچک جداگانه پرسیده می‌شود. تب «ثبت فروش» فهرست جست‌وجوی مستقل دارد تا انتخاب کالا و فروش در همان صفحه انجام شود. «گزارش» بازهٔ تاریخ را دریافت می‌کند و خروجی CSV می‌دهد. پس از خطای «اطلاعات تغییر کرده»، فهرست تازه‌سازی می‌شود و کاربر می‌تواند دوباره تصمیم بگیرد.
